# GyverStepper

Производительная библиотека для управления шаговыми моторами с Arduino. Предоставляет полный набор инструментов для работы с шаговыми двигателями: от простого управления одним мотором до многоосевого планирования траекторий для станков с ЧПУ.

## ✨ Особенности

- **Поддержка различных типов драйверов:**
  - STEP-DIR драйверы (A4988, DRV8825, TMC2208 и др.)
  - 4-проводные драйверы (ULN2003 и аналоги)
  - Полушаговый режим для 4-проводных драйверов
  - Виртуальные драйверы для тестирования

- **Гибкие режимы работы:**
  - Вращение с заданной скоростью с плавным разгоном и торможением
  - Следование к позиции с ускорением и ограничением скорости
  - Следование к позиции с заданной скоростью (без ускорения)

- **Высокая производительность:**
  - Быстрый алгоритм управления шагами
  - Оптимизация для работы в прерываниях таймера
  - Максимальная скорость до 37000 шаг/с
  - Целочисленные вычисления для минимальной нагрузки на МК

- **Многоосевой планировщик:**
  - Синхронное управление несколькими моторами
  - Трапецеидальный профиль скорости (планировщик 2-го порядка)
  - Буферизация траекторий для плавного движения
  - Компенсация люфта

- **Дополнительные возможности:**
  - Автоматическое отключение питания при достижении цели
  - Поддержка пина Enable (EN)
  - Работа в градусах и шагах
  - Абсолютные и относительные координаты

## 🚀 Быстрый старт

### Установка

#### Через менеджер библиотек Arduino IDE

1. Откройте Arduino IDE
2. Перейдите в **Скетч → Подключить библиотеку → Управлять библиотеками...**
3. Введите в поиске **GyverStepper**
4. Нажмите **Установить**

#### Ручная установка

1. Скачайте библиотеку в формате ZIP
2. В Arduino IDE выберите **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку...**
3. Укажите скачанный архив

#### Установка в PlatformIO

Добавьте в файл `platformio.ini`:

```ini
lib_deps =
    gyverlibs/GyverStepper
```

### Минимальный пример

```cpp
#include <GyverStepper.h>

// Создаём объект мотора: 2048 шагов на оборот, пины 5, 3, 4, 2
GStepper<STEPPER4WIRE> stepper(2048, 5, 3, 4, 2);

void setup() {
  Serial.begin(115200);

  // Настройка параметров движения
  stepper.setMaxSpeed(400);        // Максимальная скорость: 400 шаг/с
  stepper.setAcceleration(300);    // Ускорение: 300 шаг/с²
  stepper.autoPower(true);         // Автоотключение при достижении цели

  // Включить мотор
  stepper.enable();

  // Отправить мотор на позицию 1024 шага
  stepper.setTarget(1024);
}

void loop() {
  // Вызывать как можно чаще для работы мотора
  stepper.tick();

  // Если мотор доехал до цели
  if (!stepper.tick()) {
    // Отправить в противоположную сторону
    static bool dir = false;
    dir = !dir;
    stepper.setTarget(dir ? -1024 : 1024);
  }
}
```

## 🛠 Использование

### Выбор класса

Библиотека предоставляет несколько классов для разных задач:

- **`Stepper`** (StepperCore.h) — базовый класс для ручного управления шагами
- **`GStepper`** (GyverStepper.h) — полная функциональность, много настроек
- **`GStepper2`** (GyverStepper2.h) — облегчённая версия, оптимизирована для прерываний
- **`GPlanner`** (GyverPlanner.h) — многоосевой планировщик с остановкой в каждой точке
- **`GPlanner2`** (GyverPlanner2.h) — планировщик с буфером траекторий

### Инициализация

#### STEP-DIR драйвер

```cpp
// Без пина Enable
GStepper<STEPPER2WIRE> stepper(шаговНаОборот, step, dir);

// С пином Enable
GStepper<STEPPER2WIRE> stepper(шаговНаОборот, step, dir, en);
```

#### 4-проводной драйвер

```cpp
// Полношаговый режим
GStepper<STEPPER4WIRE> stepper(шаговНаОборот, pin1, pin2, pin3, pin4);

// Полушаговый режим
GStepper<STEPPER4WIRE_HALF> stepper(шаговНаОборот, pin1, pin2, pin3, pin4);

// С пином Enable
GStepper<STEPPER4WIRE> stepper(шаговНаОборот, pin1, pin2, pin3, pin4, en);
```

### Основные функции

#### Управление движением

```cpp
// Установить целевую позицию (абсолютная)
stepper.setTarget(1024);

// Установить целевую позицию (относительная)
stepper.setTarget(100, RELATIVE);

// Установить целевую позицию в градусах
stepper.setTargetDeg(90.0);

// Получить текущую позицию
int32_t pos = stepper.getCurrent();

// Получить целевую позицию
int32_t target = stepper.getTarget();
```

#### Настройка скорости и ускорения

```cpp
// Максимальная скорость в шагах/сек
stepper.setMaxSpeed(400);

// Максимальная скорость в градусах/сек
stepper.setMaxSpeedDeg(200);

// Ускорение в шагах/сек²
stepper.setAcceleration(300);

// Ускорение в градусах/сек²
stepper.setAccelerationDeg(150);
```

#### Режимы работы

```cpp
// Режим следования к позиции
stepper.setRunMode(FOLLOW_POS);
stepper.setTarget(1000);

// Режим поддержания скорости
stepper.setRunMode(KEEP_SPEED);
stepper.setSpeed(200);  // 200 шаг/сек
```

#### Управление питанием

```cpp
// Включить мотор
stepper.enable();

// Выключить мотор
stepper.disable();

// Автоотключение при достижении цели
stepper.autoPower(true);
```

#### Остановка

```cpp
// Плавная остановка с ускорением
stepper.stop();

// Жёсткая остановка
stepper.brake();

// Сброс позиции в 0
stepper.reset();
```

### Работа с планировщиком (многоосевые системы)

```cpp
#include "GyverPlanner.h"

// Создаём моторы
Stepper<STEPPER2WIRE> stepper1(2, 3);
Stepper<STEPPER2WIRE> stepper2(4, 5);

// Создаём планировщик для 2 осей
GPlanner<STEPPER2WIRE, 2> planner;

void setup() {
  // Добавляем моторы на оси
  planner.addStepper(0, stepper1);  // Ось X
  planner.addStepper(1, stepper2);  // Ось Y

  // Настройка параметров
  planner.setAcceleration(500);
  planner.setMaxSpeed(500);

  // Установить целевую точку
  int32_t target[] = {1000, 500};
  planner.setTarget(target);
}

void loop() {
  // Вызывать часто для работы планировщика
  planner.tick();

  // Если достигли цели
  if (planner.ready()) {
    // Новая точка маршрута
    int32_t newTarget[] = {0, 0};
    planner.setTarget(newTarget);
  }
}
```

```cpp
GStepper2<STEPPER2WIRE> stepper(2048, 2, 3);

void setup() {
  // Настройка таймера (пример для AVR)

  OCR1A = stepper.getPeriod();
}

void loop() {
  // Основной код программы
}
```

## 📚 Компоненты библиотеки

### StepperCore

Базовый класс для управления шаговым мотором. Предоставляет низкоуровневые функции:

- Управление пинами драйвера
- Выполнение шагов
- Управление направлением
- Управление питанием (Enable)

**Использование:**

```cpp
#include <StepperCore.h>

Stepper<STEPPER2WIRE> stepper(2, 3);

void setup() {
  stepper.dir = 1;  // Направление
  stepper.pos = 0;  // Позиция
}

void loop() {
  stepper.step();  // Сделать шаг
  delay(10);
}
```

### GyverStepper

Полнофункциональная библиотека с двумя алгоритмами работы:

- **Быстрый алгоритм** (по умолчанию): два таймера — для шагов и планировщика
- **Плавный алгоритм** (SMOOTH_ALGORITHM): один таймер, пересчёт на каждом шаге

**Особенности:**
- Много настроек и режимов работы
- Поддержка градусов и шагов
- Режимы FOLLOW_POS и KEEP_SPEED

### GyverStepper2

Облегчённая и оптимизированная версия:

- Меньший размер кода
- Целочисленные вычисления
- Оптимизирована для прерываний
- Два профиля: плавный (по умолчанию) и быстрый (GS_FAST_PROFILE)

**Рекомендуется для:**
- Работы в прерываниях таймера
- Движения по точкам траектории
- При ограниченных ресурсах МК

### GyverPlanner

Многоосевой планировщик с остановкой в каждой точке:

- Управление любым количеством моторов
- Синхронное движение к целевой точке
- Остановка в каждой точке траектории
- Буфер на одну следующую позицию

**Использование:**

```cpp
GPlanner<STEPPER2WIRE, 3> planner;  // 3 оси

// Добавить моторы
planner.addStepper(0, motorX);
planner.addStepper(1, motorY);
planner.addStepper(2, motorZ);

// Установить цель
int32_t target[] = {100, 200, 50};
planner.setTarget(target);
```

### GyverPlanner2

Планировщик с буферизацией траекторий:

- Буфер траекторий (по умолчанию 32 точки)
- Планирование скорости на маршруте
- Плавное движение без остановок в промежуточных точках
- Точки остановки для операций (включение инструмента и т.д.)

**Использование:**

```cpp
GPlanner2<STEPPER2WIRE, 2, 64> planner;  // 2 оси, буфер 64 точки

// Добавить точки в буфер
int32_t point1[] = {100, 200};
planner.addTarget(point1, 0);  // 0 - не точка остановки

int32_t point2[] = {200, 300};
planner.addTarget(point2, 1);  // 1 - точка остановки

// Проверить готовность
if (planner.ready()) {
  // Выполнить операцию (включить инструмент и т.д.)
  planner.resume();  // Продолжить движение
}
```

## ⚙️ Настройки компиляции

### Отключение модуля ускорения

Для уменьшения размера кода можно отключить модуль ускорения:

```cpp
#define GS_NO_ACCEL
#include "GyverStepper2.h"
```

### Быстрый профиль скорости

Для достижения максимальной скорости на участке разгона:

```cpp
#define GS_FAST_PROFILE 10  // Размер массива профиля
#include "GyverStepper2.h"
```

Участок разгона/торможения разбивается на указанное количество отрезков. Это позволяет достичь 30000 шаг/с на участке разгона (в обычном режиме в два раза меньше).

**Примечание:** Каждый участок занимает +8 байт SRAM.

### Плавный алгоритм для GStepper

```cpp
#define SMOOTH_ALGORITHM
#include <GyverStepper.h>
```

Включает плавный алгоритм движения с пересчётом скорости на каждом шаге.

### Задержка для STEP сигнала

Для некоторых драйверов может потребоваться задержка:

```cpp
#define DRIVER_STEP_TIME 4  // микросекунды
#include <StepperCore.h>
```

## 🐛 Решение проблем

### Мотор не движется

1. Проверьте подключение пинов
2. Убедитесь, что мотор включен: `stepper.enable()`
3. Проверьте установку целевой позиции: `stepper.setTarget(...)`
4. Убедитесь, что `tick()` вызывается достаточно часто

### Рывки при движении

1. Увеличьте ускорение: `stepper.setAcceleration(...)`
2. Используйте быстрый профиль: `#define GS_FAST_PROFILE`
3. Проверьте питание мотора и драйвера

### Неточное позиционирование

1. Проверьте количество шагов на оборот
2. Используйте компенсацию люфта в планировщике: `planner.setBacklash(axis, steps)`
3. Убедитесь в правильности подключения драйвера

### Большая нагрузка на МК

1. Используйте `GStepper2` вместо `GStepper`
2. Работайте в прерывании таймера с `tickManual()`
3. Отключите модуль ускорения: `#define GS_NO_ACCEL`

Подпись относится к текущей версии проекта.
